# 7. Glossário

| Termo | Significado |
|---|---|
| Arena / estabelecimento | Cliente pagante; dono de uma ou mais quadras |
| Lojinha | Página pública do estabelecimento em `/<slug>` |
| Slug | Nome curto na URL da lojinha |
| OTP | Código de uso único enviado ao telefone para o jogador entrar |
| `priceSnapshot` | Preço congelado na reserva, imune a mudança posterior da tabela |
| SaaS | Software como serviço, assinado e usado pela internet |
| ADR | Registro de decisão de arquitetura |
| DoD | Definição de pronto |
| Smoke test | Verificação rápida pós-deploy de que o essencial responde |
| Rollback | Voltar à versão anterior |
| RPO / RTO | Perda máxima de dados aceitável / tempo máximo para restabelecer |
| SemVer | Versionamento MAIOR.MENOR.PATCH |
| `-dirty` | Imagem construída com alterações não commitadas |
| Go-live | Abertura ao público e aos clientes reais |
| EAP | Estrutura analítica do projeto |
| LGPD | Lei Geral de Proteção de Dados |
